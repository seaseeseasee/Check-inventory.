ชุดติดตั้งระบบตรวจรถรีเฟอร์ PHP + MySQL
ฉบับส่งมอบ 15 กันยายน 2569 (อัปเดต v5 เบิก–เติมอุปกรณ์ 12 ตุลาคม 2569)

เริ่มที่ README-TH.md ให้เจ้าหน้าที่ IT ทำตามขั้นตอนติดตั้ง
สำหรับการอัปเดตจาก v4 เป็น v5 (เพิ่มระบบเบิก–เติมอุปกรณ์) อ่าน README-V5-RESTOCK-TH.md

สิ่งที่รวมมาให้
- public/index.html : หน้าเว็บล่าสุด รวม JavaScript, CSS และรูปโลโก้ไว้ในไฟล์แล้ว
- public/api.php : โค้ดเชื่อมฐานข้อมูลและเข้าสู่ระบบ
- public/.htaccess : การตั้งค่า Apache
- schema.sql : สร้างตารางในฐานข้อมูลใหม่ที่ว่าง (รวมตารางเบิก–เติม v5 แล้ว)
- migrations/001-add-restock.sql : สร้างตารางเบิก–เติมสำหรับฐานข้อมูล v4 เดิม (ไม่ลบข้อมูล)
- config.example.php : ตัวอย่างตั้งค่า MySQL และรหัสผ่านระบบ
- tests/test-php.php : ทดสอบด้วยข้อมูลสมมติ (ชุดเดิม)
- tests/test-restock.php : ทดสอบระบบเบิก–เติมด้วยข้อมูลสมมติ (v5 ใหม่)
- tests/index.template.html + tests/inject-assets.mjs : ต้นฉบับหน้าเว็บสำหรับพัฒนาต่อ
- tests/mock-server.mjs + tests/check-build.mjs : เครื่องมือทดสอบหน้าเว็บ (ไม่ต้องใช้ตอนติดตั้งจริง)
- README-V5-RESTOCK-TH.md : คู่มืออัปเดต v5 เวิร์กโฟลว์ API ผลทดสอบ rollback
- README-TH.md และ REVIEW-TH.md : คู่มือและผลตรวจ (ชุด v4 ต้นฉบับ)
- SHA256SUMS.txt : ค่าแฮชสำหรับตรวจความครบถ้วนของไฟล์ (ชุด v4 ต้นฉบับ)

หน้าตาล่าสุด
- ปุ่มรถเรียงซ้ายไปขวา ใช้พื้นหลังฟ้า เทา เขียว
- ทะเบียน 3ชฏ3250 / ฆง8434 / 5กล1034
- โลโก้รถมุมซ้ายบนทุกหน้า
- เอาช่องรหัสผู้ตรวจออก แต่ยังเลือกรายชื่อผู้ตรวจได้
- ไม่มีปุ่มส่งออก/สำรอง/เรียกคืนไฟล์ในหน้าเว็บ
- ปุ่มล้างประวัติอยู่ท้ายตาราง

ก่อนเปิดใช้งาน
1. เตรียม PHP 8.1+ พร้อม PDO MySQL, Apache และ MySQL 8+
2. สร้างฐานข้อมูลใหม่ แล้วนำเข้า schema.sql (มีตารางเบิก–เติมครบแล้ว)
   หรือถ้าอัปเดตจาก v4 ใช้ migrations/001-add-restock.sql ตาม README-V5-RESTOCK-TH.md
3. สร้าง config.php จาก config.example.php ใส่ข้อมูลเชื่อมต่อจริงและ hash รหัสผ่านระบบ
4. เปิดผ่าน HTTPS โดยให้เว็บเข้าถึงได้เฉพาะโฟลเดอร์ public
5. ทดสอบบน MySQL ของโรงพยาบาลด้วยข้อมูลสมมติก่อนใช้จริง
   รัน php tests/test-php.php และ php tests/test-restock.php ให้ขึ้น PASS ก่อนทุกครั้ง

รหัส preview-only-928174 ใช้กับหน้าทดลองเท่านั้น ไม่ใช่รหัสในชุดติดตั้งนี้
ไม่ต้องติดตั้ง Node.js เพื่อใช้งานชุด PHP นี้

ขอบเขตของไฟล์สำรองนี้
เป็นสำเนาโค้ดและโครงสร้างตาราง ไม่ใช่ SQL dump ของข้อมูลใช้งานจริง
ไม่มีรายชื่อ/เบอร์โทรพยาบาลจริง ไม่มีรหัสผ่านจริง และไม่รวมฐานข้อมูลทดลอง SQLite
หากต้องนำเข้ารายชื่อ ให้ใช้ไฟล์ HTML v3 ต้นฉบับที่คุณเก็บไว้ในเครื่อง
ห้ามวางไฟล์ต้นฉบับที่มีรายชื่อจริงไว้ในโฟลเดอร์ public

ยังไม่ได้ติดตั้งหรือทดสอบกับ MySQL จริงของโรงพยาบาล
อ่านข้อจำกัดใน README ก่อนใช้จริง โดยเฉพาะรหัสผ่านร่วมและขนาดประวัติสะสม
